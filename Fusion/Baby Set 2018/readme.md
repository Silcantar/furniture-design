# Baby Room Set, 2018

I designed and built this baby room set in 2018 before the birth of my first child. It has since seen use by two further children of my own. I am optimistic that it will continue to be used for many more children (albeit not my own) for many years to come.

The style is largely [Shaker](https://en.wikipedia.org/wiki/Shakers)-inspired—though of course the Shakers rarely built cribs, and never for themselves.

One interesting feature of the crib is that the short rails are joined to the posts by a joint originating in Japanese woodworking known as [shitage kama](https://hillbillydaiku.com/2015/12/15/blind-dovetail-thru-mortise-and-tenon/) (in this case, the single-wedge variant). This is a remarkable joint with many great properties:

- Uses only wooden components. 
- Can be disassembled in seconds using only a hammer, yet will never come apart in regular use.
- Can be trimmed flush with the surface of the post.
- Is extremely strong—the action of the wedge(s) draws the parts together, preventing any racking or wobbling.

Both pieces are built primarily from hard maple with walnut accents. They are finished in nontoxic pure flaxseed oil and shellac. The only exception is the top of the dresser, which is additionally finished with polyurethane because it doubles as a changing table and needs extra protection from... accidents.
