# Furniture Design

This is a repository for the furniture and other woodworking designs I've developed over the years. 

Existing designs as of February 2025 are for Fusion 360 but going forward I expect to be using FreeCAD.

Since my woodworking consists mostly of hand tools and traditional joinery, most of my designs are intended for that workflow. Most if not all can also be built using mostly machines but it may be less straightforward.
